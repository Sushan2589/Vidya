# VIDYA team portraits

These are the existing portraits from
`https://raw.githubusercontent.com/Sulav-Poudel/VIDYA-IMG/main/{id}.png`,
downloaded on 2026-10-09 and converted to WebP (quality 85, maximum 576 pixels,
orientation corrected, without enlargement). Numeric filenames preserve the
original ID mapping used by `components/TeamSection.tsx`.

Local copies avoid GitHub redirects and runtime network timeouts. Update the
corresponding local asset when a team portrait changes; keep its identity and
component mapping consistent.
