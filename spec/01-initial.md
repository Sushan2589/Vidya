We are building a website for a company named Vidya. Their initiative is to spread awareness about olympaids in Nepal which many schools don't teach/encourage.

The project setup done is done in NEXTJS,tailwind using bun as runtime and typescript and planning is to use this throughout.

This website should not be like any typical organization website just text text and text this should speak about the story.
Should contain microinteractions, various cool components, glassmorphism to make it look modern.
The ultimate vision is for any student trying to participate in an olympaid in Nepal should ultimately land here.

Plan is to use various acternity UI, ShadCN, framer motion components and other websites too which are good.


For the initial run
Design a premium full-screen landing page for a STEM Olympiad organization called VIDYA.

The hero should feature a large, cinematic background image that fills the entire viewport. Apply a subtle dark overlay (40–60%) so text remains highly readable. The image should feel inspiring and academic—students solving problems, scientific experiments, astronomy, mathematics, or a beautiful landscape that evokes curiosity.

The content should float naturally above the image rather than being inside a boxed container.

Layout:

Floating glassmorphism navbar.
Large bold headline (2–3 lines).
Short supporting paragraph.
Primary and secondary CTA buttons.
Smooth scroll indicator at the bottom.

Style:

Modern, premium, Apple/Vercel-inspired.
Minimal UI.
Plenty of whitespace.
Subtle gradients.
Soft blur and glass effects.
Elegant typography.
Smooth micro-interactions.
Framer Motion animations.
Dark overlay over the image.

Avoid making it look like an NGO or government website.


Don't hesistate in using acerternity or any other components.
